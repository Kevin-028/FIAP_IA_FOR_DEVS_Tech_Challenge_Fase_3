# Lactate and sepsis bundle

- protocol_id: PROT-SEPSIS-LACTATE
- PMID: 26903338

Hospital protocol PROT-SEPSIS-LACTATE. Elevated lactate with suspected infection triggers the sepsis bundle review (PMID 26903338). Suggested conduct: check pending cultures and lactate, alert the team, do not order antimicrobials from this assistant. REQUIRES PHYSICIAN VALIDATION.
