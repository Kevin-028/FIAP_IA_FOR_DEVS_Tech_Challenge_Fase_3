# Glucocorticoids in croup

- protocol_id: PROT-STERID-CROUP
- PMID: 10591357

Hospital protocol PROT-STERID-CROUP. Glucocorticoids reduce symptoms and return visits in croup (PMID 10591357). Suggested conduct: assess airway, Westley score, oxygen saturation, escalate if stridor at rest. REQUIRES PHYSICIAN VALIDATION.
